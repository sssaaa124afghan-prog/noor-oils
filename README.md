# مرجع الزيوت — نور الخليج للعطور

أداة بحث بالكود أو الاسم في زيوت العطور، بتقرا ملف CSV متصدّر من دفترة.

- افتح الصفحة، ودوس «استيراد» واختار ملف الـ CSV.
- البيانات بتتحفظ في المتصفح بتاع الجهاز ده بس (IndexedDB)، ومش بتترفع لأي مكان.
- قسم «العينات»: كود العينة واسمها والشركة والتاريخ والملاحظات، مع صور من الكاميرا أو المعرض (محفوظة على الجهاز بس).
- نسخة احتياطية: زرار السحابة بيحفظ ملف JSON واحد (الزيوت + العينات + صورها)، والاسترجاع بيضيف من غير ما يمسح.
- مفيش أي بيانات شركة في الريبو ده: الكود بس.
